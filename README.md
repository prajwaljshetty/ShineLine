# Shine Line

Shine Line is a website developed for an industrial contracting and manpower company based in Saudi Arabia.

## About the Project

This project was developed during my internship at ShreeshTech for Shine Line.

I worked on the development of the **homepage module**, focusing on the website structure, layout, styling, navigation, sections, and interactive elements.

## My Contribution

- Developed the homepage structure using HTML
- Designed and styled the webpage using CSS
- Implemented interactive functionality using JavaScript
- Created the navigation and homepage sections
- Integrated images and visual assets
- Implemented the responsive website layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

# Shine Line

Shine Line is a website developed for an industrial contracting and manpower company based in Saudi Arabia.

## About the Project

This project was developed during my internship at **ShreeshTech**, an IT solutions company based in India, for their client, Shine Line. I worked on the development of the **homepage module**, focusing on its structure, layout, styling, navigation, interactive elements, and responsive presentation.

The homepage was designed to present the company's services and information through a structured visual interface, including a rotating hero section, company information, services, vision and mission, key strengths, and supporting visual content.

## My Contribution

I developed the homepage structure using HTML and handled its visual styling with CSS. I implemented interactive functionality using JavaScript, created the navigation and homepage sections, integrated images and other visual assets, and worked on the responsive layout across different screen sizes.
